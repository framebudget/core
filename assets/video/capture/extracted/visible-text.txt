## Intent

A launch video for framebudget, a new open-source JavaScript library. framebudget decides, per device,
which visual effects a site can afford, so slow phones never stutter and fast phones keep everything.
At 60 Hz every frame has a 16.7 ms budget; each effect (parallax, page transitions, canvas animations,
sounds, blur) spends part of it. framebudget measures how much budget a device really has and allows
only the effects that fit. Tone: precise, engineered, calm confidence. Dark theme. No voiceover: the
on-screen text carries the whole story.

Story arc, in order:

1. The problem: a beautiful animated site stuttering on a slow phone; frame bars overshoot the 16.7 ms
   vsync line.
2. The idea: every effect costs frame time, shown as segments filling a frame budget.
3. How it works, quick beats: decide before first paint (tiny inline boot script); warm benchmark score
   (100 = reference phone, cold before paint, warm at load, cached); per-effect thresholds with
   hysteresis (not one global tier); runtime governor stepping effects down one at a time as a device
   heats up; local learning (remembers what stuttered, nothing leaves the device); optional opt-in
   telemetry (off by default, enabled by the site developer, anonymous, sampled, never with GPC or
   Save-Data).
4. The code: `npm i framebudget`, then the API typed on screen:
   `import { budget } from "framebudget";`, `budget.allows("parallax");`,
   `budget.on("change", update);`, `useBudget("pageTransition");` (from `framebudget/react`).
5. End card: the Deadline logo, "Keep the effects. Lose the stutter.", `npm i framebudget`.

## Customizations

- Dark-first palette from the brand's dark roles; the final values from the dark brand pass replace them before the final render.
- Effect colors keep their meaning across the video: parallax amber, page transition violet, canvas mint, sound cyan, blur blue, app work stone; vsync line pink at 16.7 ms.
- Code is typed on screen in Martian Mono.
- Tier names, when shown: Full, High, Medium, Lite. Mention prefers-reduced-motion is respected.
