Three ways to draw a 16.7 ms frame

Each direction starts from the same fact: at 60 Hz a frame has 16.7 ms, and every effect spends part of it. They differ in which picture of that fact they make memorable.

Deadline was chosen, and it now ships dark first: Night is the default page and the light theme remains only as tokens for documentation. The boards below show the directions as they were first explored. The brand guide has the final dark palette.

Risk

Why Deadline

It is the only direction where the logo, the docs diagrams and the product's own debug overlay are the same drawing. Developers already read flame charts and frame bars in their devtools, so the mark explains the library before the tagline does.

It also survives the hard cases: a 16 px favicon, one-color print, and a light documentation theme. Phosphor is the more atmospheric idea and can return as the look of the debug overlay. Sixty's frame counting lives on in the motion system, where durations are written in frames.

After review the identity moved to dark first. The mark was already drawn on Ink, so the bars and the vsync line now sit straight on the page, and the light theme stays behind as tokens for documentation.
